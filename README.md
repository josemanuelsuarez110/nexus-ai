# NEXUS AI - DevSecOps SaaS Platform

NEXUS AI es una plataforma de inteligencia DevSecOps y dashboard de análisis de código para portafolios profesionales.

## Características Principales
- **Nexus Copilot Assistant**: Herramienta de diagnóstico interactiva.
- **Dashboard de Proyectos**: Gestión CRUD de repositorios con Supabase.
- **Inspector en vivo**: Integración directa con la API de GitHub.
- **Autenticación Segura**: Integración con Supabase Auth y Middleware.

## Stack Tecnológico
- Next.js 16 (App Router), TypeScript, Tailwind CSS, Supabase.
