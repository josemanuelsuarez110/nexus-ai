# 🛡️ NEXUS AI - DevSecOps SaaS Platform

NEXUS AI is an advanced DevSecOps intelligence platform and automated code analysis dashboard built for professional portfolios and secure software development lifecycle management.

## 🚀 Key Features
- **🤖 Nexus Copilot Assistant**: Interactive AI-powered diagnostic tool for architecture, code quality, and security assessments.
- **📁 Projects & Repositories Dashboard**: CRUD management for monitored GitHub repositories connected directly to Supabase.
- **🔍 Live GitHub Inspector**: Real-time integration with the GitHub API to fetch metrics, open issues, stars, and language breakdowns.
- **🔐 Secure Authentication**: Supabase Auth integration supporting Email/Password and GitHub OAuth with protected Next.js Middleware routes.
- **⚡ Modern Tech Stack**: Built with Next.js 16 (App Router), Tailwind CSS, TypeScript, and Supabase (PostgreSQL / RLS).
