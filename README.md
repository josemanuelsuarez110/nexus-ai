## 📌 Visión General
NEXUS AI integra herramientas de observabilidad de repositorios con modelos de analisis estatico y dinamico.

### 🌟 Funcionalidades Clave
- 🤖 **Copilot AI Diagnostic Engine:** Asistente interactivo integrado para analisis de calidad de codigo y remediaciones de seguridad.
- 📊 **Repositories Dashboard:** Panel interactivo conectado a Supabase (PostgreSQL) para la gestion CRUD de proyectos.
- 🔍 **GitHub API Live Inspector:** Inspeccion en tiempo real de metricas, lenguajes e issue tracking.
- 🔐 **Enterprise Auth & Middleware:** Autenticacion con Supabase Auth (OAuth/Email) y proteccion de rutas con Middleware.
- ⚡ **Modern Stack:** Construido sobre Next.js 16 App Router y Tailwind CSS.
